# CV Online — Rizqi Ghani Adinata

Website resume / CV online pribadi mahasiswa Program Studi **Sistem Informasi**, Universitas Nahdlatul Ulama (UNUGHA) Cilacap.

## Fitur
- 7 elemen semantik HTML5: `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<aside>`, `<footer>`
- Layout responsif **mobile-first** dengan CSS murni (breakpoint 640px & 1024px)
- Menu hamburger tanpa JavaScript (CSS checkbox)
- Aksesibilitas: skip link, `aria-label`, `aria-labelledby`, `lang="id"`, kontras warna

## Teknologi
- HTML5 semantik
- CSS3 murni (tanpa framework)

## Deployment
- **Cloudflare Pages**
- **GitHub Pages** (repo ini)
